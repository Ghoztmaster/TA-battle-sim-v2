# Tiberium Alliances Battle Simulator V2 (maintained fork)

TABS lets you simulate an attack in Tiberium Alliances before you actually send it: set up your formation, run the battle, and see the outcome, losses and repair times. Upstream maintenance stopped in 2023 (last version 23.05.31 by NetquiK); this fork keeps the script working with current game versions.

## Install

1. Install [Tampermonkey](https://www.tampermonkey.net/) in your browser.
2. Open <https://packetlab.nl/shockr/scripts/TA_Tiberium_Alliances_Battle_Simulator_V2.user.js> and click **Install** (or **Update**).

## Already running TABS?

Your current install still checks NetquiK's GitHub for updates, so it will not find this fork by itself. Open the link above once: Tampermonkey recognises it as the same script and offers to update it in place. Your TABS settings are kept (they live in the game's local storage, not in Tampermonkey). After that, updates arrive automatically.
